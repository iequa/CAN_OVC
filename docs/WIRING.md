# CAN_OVC — схема разводки адаптера

Ревизия C, 31.10.2026  
Назначение: Vectra C full CAN, MS-CAN 95.238 кбит/с, CID/GID + CD70/DVD90.

> Перед подключением к машине прошивка должна быть в **listen-only**:
> текущая версия передаёт `0x691` и `0x6C1`.

Полная русская версия: `docs/WIRING_rus_v2.md`.  
Схема: `docs/wiring_rus_v2.svg` / `.png`.

## 1. Общая структура

```text
12V ACC/GND
   |
 [F1] [Q1 reverse] [D1 TVS] [Mini360 12->5V] [MCP1700 5->3.3V]
                                      |               |
                                      |               +--> PCM5102A 3V3
                                      +--> ESP32 5V
                                      +--> MCP2515/TJA1050 5V
                                      +--> Q2 -> relay coil (12V)

Car MS-CAN  <-> SN65HVD230 <-> ESP32 TWAI (GPIO17/16)
CID         <-> relay K1 <-> MCP2515/TJA1050 <-> level shifter <-> ESP32 SPI
```

## 2. Питание

| Обозначение | Компонент | Подключение |
|---|---|---|
| J1 | 12V ACC / GND | ACC через предохранитель, GND на массу |
| F1 | предохранитель 1 A | между J1 +12V и схемой |
| Q1 | защита от переполюсовки | P-MOSFET или готовая плата |
| D1 | TVS, например SMBJ18A | +12V ↔ GND, после Q1 |
| U1 | Mini360 #1 | 12V → 5.0V, 3A; выход на 5V rail |
| U2 | Mini360 #2 | опционально, резерв |
| U3 | MCP1700-3302E/TO | 5V → 3.3V только для PCM5102A |
| C1 | 1000 мкФ / 35V, 105 °C | вход 12V, после Q1 |
| C2 | 100 нФ / 50V X7R | вход 12V |
| C3 | 470 мкФ / 16V, 105 °C + 100 нФ / 50V | 5V rail |
| C4 | 1 мкФ / 25V X7R | вход MCP1700 |
| C5 | 10 мкФ / 25V X7R + 100 нФ / 50V | выход MCP1700 |

Проверить выход Mini360 мультиметром **до подключения ESP32**: ровно 5.0 В.

MCP1700 TO-92: обычно `1 = GND`, `2 = VIN`, `3 = VOUT`; проверить по даташиту.

Порядок питания: **F1 → Q1 → D1**. При переполюсовке Q1 закрывается,
TVS не открывается, предохранитель остаётся целым. TVS защищает
от положительных выбросов и load dump.

## 3. ESP32

| ESP32 | Подключение |
|---|---|
| GPIO17 | SN65HVD230 TXD (car side) |
| GPIO16 | SN65HVD230 RXD (car side) |
| 3V3 | SN65 VCC, level shifter VA, pull-up ACC |
| GND | общая земля |
| GPIO18 | level shifter A1 → MCP2515 SCK |
| GPIO19 | level shifter A2 ← MCP2515 MISO |
| GPIO23 | level shifter A3 → MCP2515 MOSI |
| GPIO21 | level shifter A4 → MCP2515 CS |
| GPIO22 | level shifter A5 ← MCP2515 INT |
| GPIO26 | PCM5102A BCLK |
| GPIO25 | PCM5102A LR / LRCK |
| GPIO27 | PCM5102A DATA / DIN |
| GPIO34 | ACC optocoupler collector (input only) |
| GPIO32 | relay driver |
| 5V/VIN | Mini360 5V |
| GND | общая земля |

Не использовать GPIO1/3 (UART0), GPIO0/2/5/12/15 (strapping), GPIO6–11 (flash).

## 4. CAN со стороны автомобиля

| SN65HVD230 | Подключение |
|---|---|
| 1 TXD | ESP32 GPIO17 |
| 2 GND | GND |
| 3 VCC | 3.3V |
| 4 RXD | ESP32 GPIO16 |
| 5 VREF | не подключать |
| 6 CANL | car MS-CAN L |
| 7 CANH | car MS-CAN H |
| 8 RS | GND |

- **Выпаять встроенный 120 Ом** на SN65HVD230, который стоит на стороне авто.
- Со стороны авто терминаторы уже есть в шине.
- Первый съём: OBD-II пины 3 (MS-CAN H) и 11 (MS-CAN L), либо CID 19/20.
- Не подключать одновременно обе пары MS-CAN.

## 5. Gateway и CID

MCP2515-модуль с TJA1050 питается от **5 В**. Его SPI — 5 В, поэтому нужен level shifter.

| MCP2515 | Level shifter | ESP32 |
|---|---|---|
| SCK | B1 ↔ A1 | GPIO18 |
| MISO | B2 ↔ A2 | GPIO19 |
| MOSI | B3 ↔ A3 | GPIO23 |
| CS | B4 ↔ A4 | GPIO21 |
| INT | B5 ↔ A5 | GPIO22 |
| VDD | VB = 5V | — |
| GND | GND | GND |

Level shifter: TXS0108E или аналогичный; `VA=3.3V`, `VB=5V`, `OE=3.3V`, общий GND.

MCP2515/TJA1050:

- VDD = 5V;
- GND = GND;
- CANH/CANL → relay K1 NO contacts;
- на модуле уже есть 120 Ом.

## 6. Реле bypass

**Fujitsu RY12W-K** — подходит:

- DPDT, 2 перекидных контакта (2 Form C);
- катушка 12 В, 960 Ом, ≈ 12.5 мА;
- контакты 1 А, до 24 В DC / 120 В AC;
- сигнальные цепи CAN (единицы мА) — с большим запасом.

```text
K1 COM1 -> CID CAN H
K1 NC1  -> car CAN H
K1 NO1  -> MCP/TJA CAN H

K1 COM2 -> CID CAN L
K1 NC2  -> car CAN L
K1 NO2  -> MCP/TJA CAN L
```

- реле обесточено → CID напрямую на шину авто (bypass);
- реле включено → CID через gateway;
- управление: GPIO32 → R3 1k → Q2 (2N2222A/BC547/S8050) → катушка на +12 В;
- D2 1N4007/1N4148 параллельно катушке, катод к +12 В;
- при глубоком сне/сбросе GPIO32 = 0 → bypass.

Распиновку реле проверить мультиметром: катушка ≈ 960 Ом, остальные выводы — контактные группы.

## 7. ACC / зажигание

```text
J5 ACC 12V ── R1 4.7k ── PC817 pin1 (LED anode)
PC817 pin2 (LED cathode) ── GND

PC817 pin4 (collector) ── GPIO34
GPIO34 ── R2 10k ── 3.3V
GPIO34 ── C6 100nF ── GND
PC817 pin3 (emitter) ── GND
```

При ACC = 12V транзистор открыт, GPIO34 = LOW.  
В прошивке учесть инверсию. R1 = 2.2–4.7 кОм (4.7 кОм ≈ 2.3 мА через LED).

Развязка: PC817 передаёт сигнал светом, поэтому 12 В, выбросы и помехи
зажигания не попадают на GPIO34. Это локальная развязка входа, а не
полная гальваническая изоляция: питание устройства идёт от той же 12 В,
земли в итоге общие. R2 + C6 задают уровень и фильтр, в прошивке нужен
антидребезг 200–500 мс.

## 8. Аудио

PCM5102A v2 питается **только от 3.3 В**.

| PCM5102A | Подключение |
|---|---|
| 3V3 | выход MCP1700 3.3V |
| GND | GND |
| BCLK | ESP32 GPIO26 |
| LR | ESP32 GPIO25 |
| DATA | ESP32 GPIO27 |
| MCLK | GND (внутренний PLL) |
| Left | через делитель → radio AUX L |
| Right | через делитель → radio AUX R |
| GND | radio AUX GND |

Делитель на канал:

```text
DAC L ── C7 10uF ── R4 10k ──┬── radio AUX L
                              R6 10k
                              │
                             GND
```

- `R4=R6=10k` — примерно 2:1;
- если нужно тише — `R4=20k`, `R6=10k`;
- проверить, есть ли AUX на CD70/DVD90; если нет — нужен CDC-эмулятор/FM-модулятор;
- экран аудиокабеля — на GND со стороны магнитолы.

## 9. Что докупить

Полный список по блокам — в `docs/WIRING_rus_v2.md`, раздел 9.
Кратко, с учётом того, что MCP1700 и PCM5102A уже есть:

- электролиты 1000 мкФ/35V, 470 мкФ/16V, 10 мкФ/25V ×2, керамика 1 мкФ/25V ×2, 100 нФ/50V ×5;
- SN65HVD230 (3.3 В), MCP2515+TJA1050 (5 В), TXS0108E;
- реле RY12W-K, Q2 2N2222A, R3 1 кОм, D2 1N4007;
- PC817, R1 4.7 кОм, R2 10 кОм, C6 100 нФ;
- C7/C8 10 мкФ, R4–R7 10 кОм, экранированный кабель, разъём AUX;
- OBD-II разъём/пигтейл, разъём CID, провод, корпус, крепёж.

## 10. Порядок проверки

1. Стенд: питание 12V, проверить 5V и 3.3V.
2. Проверить SN65HVD230 без 120 Ом.
3. Проверить MCP2515 через level shifter.
4. Прозвонить реле и проверить: обесточено — CID напрямую; включено — через gateway.
5. Проверить PCM5102A на наушники/усилитель.
6. Проверить ACC: 12 В → GPIO34 = 0.
7. Только потом — машина, сначала listen-only.
